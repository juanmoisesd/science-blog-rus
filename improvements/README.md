# Systematic Improvement of Juan Moisés de la Serna's Research Documents

This directory contains improved versions of the research documents (Press Releases and SERNA Scales) authored by Juan Moisés de la Serna on Zenodo.

## Structure
- `press_releases/`: Improved versions of institutional press releases following a professional 10-point roadmap.
- `serna_scales/`: Improved psychometric scale frameworks replacing placeholder content with professional standards.
- `roadmap_global_es.md`: Master strategy for the author to update all existing ~170 records.

## Methodology
Each document has been enhanced to include:
1.  **Narrative Headlines:** Moving away from generic "Press Release" titles.
2.  **Scientific Findings:** Providing actual data summaries instead of keywords.
3.  **FAIR Compliance:** Explicitly stating open science practices and licenses.
4.  **Professional Formatting:** Adhering to international standards for science communication and psychometry.
